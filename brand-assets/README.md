# Brand assets (not served)

Original and older logo, icon and animation files that the website no longer uses. Kept here, outside `public/`, so they are not deployed but are not lost.

- `logo.png`: original logo export
- `elevatehq-logo-dark.svg`, `elevatehq-logo-dark-1024.png`: earlier logo version (before the Playfair wordmark)
- `icon.png`, `elevatehq-icon-512.png`: earlier icons (the site now uses `app/icon.svg` and `app/apple-icon.png`)
- `brain3d.json`: an earlier data file for the hero animation (the hero uses `public/mind-of-light/veins3d.json`)
